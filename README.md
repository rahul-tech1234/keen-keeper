# Name of the project

KeenKeeper is a modern React-based web application .

# A short description 
A modern and user-friendly web application for organizing and managing personal collections efficiently.

# Technologies Used

- React
- React Router
- React Toastify
- React Icons
- Tailwind CSS
- DaisyUI
-Recharts

# Key Features

1. Dynamic routing and seamless navigation using React Router.
2. Interactive notifications and alerts with React Toastify.
3. Modern, responsive, and user-friendly UI built with Tailwind CSS and DaisyUI.
